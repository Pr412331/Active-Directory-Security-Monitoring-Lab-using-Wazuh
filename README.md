# Active Directory Security Monitoring Lab using Wazuh
I designed and implemented a structured Active Directory lab environment centered around a Domain Controller with a well-organized OU hierarchy, including top-level segregation for departments, groups, service accounts, and quarantine, with each department further containing dedicated users and computers OUs to mirror real-world enterprise architecture. Leveraging PowerShell, I automated the user provisioning process to streamline account creation and dynamically assign users to their respective departments, reducing manual overhead while maintaining consistency and scalability. The project follows a security-focused design philosophy, incorporating logical separation of resources and preparing the foundation for RBAC and GPO-based controls. To extend visibility and operational monitoring, the environment is integrated with Wazuh SIEM, enabling centralized logging, threat detection, and security analytics. This lab demonstrates practical expertise in Active Directory design, automation, and SIEM integration, showcasing the ability to build and manage enterprise-grade identity infrastructure with a focus on efficiency, security, and real-world applicability.
